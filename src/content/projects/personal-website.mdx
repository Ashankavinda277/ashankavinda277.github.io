## Project Overview

This website serves as my personal developer portfolio and technical workspace. It was engineered to emphasize clean typography, fast performance, generous whitespace, and dynamic content management.

## Problem Statement

Many software engineering portfolios rely on bloated templates or generic low-contrast visuals. The objective of this project was to construct a distinct technical workspace that feels like a polished developer tool.

## Project Goals

- **Performance First**: Static HTML generation using Astro for near-instant page loads.
- **Zero Hardcoding**: Extensible content collections for projects, experience, and skills.
- **Selective Interactivity**: Client-side React islands hydrated strictly when needed (Terminal mode, theme switcher, command palette).
- **Minimal Aesthetic**: Monochrome base palette with a crisp electric emerald accent.

## Key Features

- **Data-Driven Architecture**: Creating a new `.mdx` file automatically publishes dynamic case studies without layout code changes.
- **Developer Terminal Mode**: Interactive terminal allowing visitors to execute `$ whoami`, `$ skills`, and `$ projects`.
- **Keyboard Navigation**: Command palette shortcuts (`Cmd + K`) for instant navigation across sections.

## Lessons Learned

- Leveraging Astro Content Collections for type-safe static site publishing.
- Optimizing hydration boundaries with React island components.

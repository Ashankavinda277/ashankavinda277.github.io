## Project Overview

Document AI is an experimental microservice designed to parse unstructured enterprise documents and extract structured JSON metadata using Amazon Bedrock foundation models.

## Key Features

- **Semantic Extraction**: Parses PDFs and images into structured fields.
- **FastAPI Endpoints**: High-throughput REST API interface.

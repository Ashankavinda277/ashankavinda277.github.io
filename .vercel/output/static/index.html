Background & Philosophy

About Me

An undergraduate IT student focused on building practical, scalable web and cloud software.

Hi, I'm Ashan Kavinda. I'm currently an Information Technology undergraduate with a deep passion for building full-stack applications and cloud-backed software.

My development journey centers on practical software engineering. Rather than trying to claim expert status across every tool, I focus on understanding fundamental concepts, writing clean type-safe code, and building systems that solve real operational problems.

I work primarily with React, Next.js, TypeScript, and Python (FastAPI) on the software layer, alongside AWS cloud services (Amplify, AppSync, DynamoDB, Cognito) for backend infrastructure. Recently, I've been actively exploring AI integration with Amazon Bedrock to bring intelligent automation to web tools.

When I'm not writing code for coursework or personal projects, I enjoy reading technical documentation, learning modern system architecture patterns, and refining my development workspace.

Core Focus Areas

  • Full-Stack Development Type-safe frontend React/Next.js interfaces paired with FastAPI or serverless backends.
  • Cloud Infrastructure AWS serverless services (Amplify, AppSync, DynamoDB, Cognito authentication).
  • Practical AI & Automation Integrating LLM APIs and intelligent processing workflows into web applications.
